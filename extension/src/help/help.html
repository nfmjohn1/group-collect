🚀 Getting Started

Group Collect is a Chrome extension that helps you manage Facebook group member requests efficiently by automating data collection, exports, and member filtering.

Installation

  1. Install the Group Collect extension from the Chrome Web Store
  2. Pin the extension to your toolbar for easy access
  3. Navigate to your Facebook group's member requests page
  4. Click the extension icon to open the popup

First Time Setup

  1. Open the extension popup by clicking the icon
  2. Go to Settings
  3. (Optional) Add your Google Sheets URL for automatic exports
  4. Configure decline rules if you want to auto-filter member requests
✓ Pro Tip: The extension badge shows the number of pending member requests in real-time!

👥 Collecting Members

The core feature of Group Collect is automated member data collection from Facebook group requests.

How to Collect Member Data

  1. Navigate to your Facebook group's member requests page
  2. Make sure you can see the pending member requests on the page
  3. Click the Group Collect extension icon
  4. Click the "Collect Members" button
  5. Wait for the collection process to complete (you'll see a notification)

What Data is Collected?

  • Facebook Username: The member's Facebook profile name
  • Profile URL: Link to their Facebook profile
  • Join Date: When they requested to join
  • Approval Questions (Q1-Q3): Answers to your group's membership questions
  • Status: Pending, Approved, or Declined
Note: All data is stored locally in your browser using Chrome's storage API. Nothing is sent to external servers.

Viewing Collected Members

After collecting member data, you can:

  • View the total count in the popup Home page
  • Click "View Data" to open the full dashboard
  • Export to CSV or push to Google Sheets

📊 Google Sheets Integration

Export your member data directly to Google Sheets for advanced analysis and record-keeping.

Setting Up Google Sheets

  1. Create a new Google Sheet (or use an existing one)
  2. Copy the sheet URL from your browser
  3. Open Group Collect Settings
  4. Paste the URL in the "Google Sheet URL" field
  5. Click "Save URL"

Syncing Questions Mapping

Before pushing data, sync the question mapping:

  1. Make sure you have collected member data first
  2. Click "SYNC QUESTIONS/ANSWERS" in Settings
  3. This creates the proper column headers in your sheet

Pushing Data to Sheets

You can export data in two ways:

  • From Home: Click "Push to Sheet" button
  • From Dashboard: Click "Push to Google Sheet" in the action bar
Note: The first time you push data, you'll need to grant the extension permission to access your Google account.

Sheet Format

Your Google Sheet will have the following columns:

Group Name | Facebook Username | Joined On | Q1 | Q2 | Q3 | Status | Date Added

⚡ Auto-Decline Feature

Automatically decline member requests that don't meet your criteria, saving you time on manual review.

⚠️ Warning: Auto-declined members are permanently declined on Facebook and cannot be easily restored. Configure rules carefully!

Enabling Auto-Decline

  1. Go to Settings
  2. Find the "Auto-Decline Feature" toggle
  3. Click the toggle (you'll see a confirmation warning)
  4. Confirm to enable the feature

Configuring Decline Rules

Once enabled, you can configure four types of rules:

Email Required

Decline if email is missing from Q1, Q2, or Q3 answers

Question 1 Required

Decline if first approval question is unanswered

Question 2 Required

Decline if second approval question is unanswered

Question 3 Required

Decline if third approval question is unanswered

How Auto-Decline Works

  1. The extension monitors your Facebook group members page
  2. When new members are detected, it evaluates them against your rules
  3. If a member fails any enabled rule, they are automatically declined
  4. All declines are logged with reasons for your records
  5. You receive notifications when members are declined

Decline Log

Every auto-declined member is logged with:

  • Member name and ID
  • Group name
  • Decline reason (e.g., "Email address missing")
  • Timestamp of decline

📈 Data Dashboard

The dashboard provides a comprehensive view of all collected member data with powerful filtering and export capabilities.

Dashboard Features

  • Statistics: View total, pending, approved, and declined member counts
  • Search: Search across username, name, group, and Q&A answers
  • Filters: Filter by status (pending/approved/declined) or group name
  • Sorting: Click column headers to sort by group, username, date, or status
  • Pagination: View 10, 25, 50, or 100 members per page
  • Bulk Selection: Select multiple members for batch operations

Action Buttons

Download to CSV

Export selected or all filtered members to a CSV file

Push to Google Sheet

Sync all data to your configured Google Sheet

Open Google Sheet

Quick link to view your Google Sheet

Clear All Data

Delete all member data (requires confirmation)

Using Filters

  1. Search: Type in the search bar to find specific members
  2. Status: Select "Pending", "Approved", or "Declined" from dropdown
  3. Group: Select a specific group from the dropdown
  4. Clear: Click "Clear Filters" to reset all filters

💾 Backup & Restore

Group Collect automatically backs up your data daily and provides manual backup options.

Automatic Backups

  • Daily backups are created automatically at midnight
  • Last 7 days of backups are kept in Chrome storage
  • Backups include all members, settings, and decline logs

Creating a Manual Backup

To create a manual backup (future feature):

  1. Send a message to the background script with type "CREATE_BACKUP"
  2. The backup will be downloaded as a JSON file
  3. Save this file in a safe location

Restoring from Backup

To restore from a backup (future feature):

  1. Send a message to the background script with type "RESTORE_BACKUP"
  2. Include the backup JSON data in the message
  3. All data will be restored from the backup
⚠️ Warning: Restoring from a backup will overwrite all current data. Make sure you have a recent backup before restoring!

⚙️ Settings

Configure Group Collect to match your workflow and preferences.

Available Settings

  • Auto-Decline Feature: Enable/disable automatic member filtering
  • Decline Rules: Configure which criteria trigger auto-decline

Changing Settings

  1. Click the extension icon to open the popup
  2. Navigate to the Settings page
  3. Modify your preferences
  4. Click "Save" buttons to persist changes

🔧 Troubleshooting

Extension Not Collecting Members

  • Make sure you're on the Facebook group members page
  • Check that member requests are visible on the page
  • Refresh the page and try again
  • Check browser console for errors (F12 → Console)

Google Sheets Not Working

  • Verify the Google Sheet URL is correct
  • Make sure you granted permissions when prompted
  • Try clicking "SYNC QUESTIONS/ANSWERS" first
  • Check that the sheet is not protected or read-only

Auto-Decline Not Working

  • Verify the feature is enabled (toggle is ON)
  • Check that at least one decline rule is configured
  • Make sure you're on the Facebook group members page
  • Facebook UI changes may require selector updates

Badge Not Showing Correct Count

  • Collect member data again to refresh counts
  • Send a message with type "UPDATE_BADGE" to refresh manually
  • Check Chrome storage for data consistency

Viewing Error Logs

To view detailed error logs:

  1. Send a message to background script with type "GET_ERROR_LOG"
  2. Review the error log entries
  3. Report persistent issues on GitHub

❓ Frequently Asked Questions

Is my data secure?

Yes! All data is stored locally in your browser using Chrome's storage API. Nothing is sent to external servers except when you explicitly push to Google Sheets.

Can I use this with multiple groups?

Yes! The extension automatically detects which group you're viewing and stores data accordingly. You can filter by group in the dashboard.

What happens if I decline someone by mistake?

Declined members are permanently declined on Facebook. However, they can request to join again, and you can approve them at that time.

Does this work with Facebook's new interface?

The extension is designed to work with Facebook's current interface. If Facebook updates their UI, the extension may need updates to continue working.

Can I export data to Excel?

Yes! Use the "Download to CSV" button, which creates a file that can be opened in Excel, Google Sheets, or any spreadsheet application.

How often does automatic backup run?

Automatic backups run once every 24 hours. The last 7 backups are kept in Chrome storage.

Can I customize the decline rules?

Currently, you can configure email requirements and required questions. Custom regex rules are planned for a future update.

What permissions does the extension need?

  • Storage: To save member data locally
  • Notifications: To alert you about new members and events
  • Identity: To authenticate with Google for Sheets export
  • Active Tab: To collect data from Facebook pages
