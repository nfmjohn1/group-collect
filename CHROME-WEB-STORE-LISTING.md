📊 GROUP COLLECT - Streamline Your Facebook Group Management

Group Collect is the ultimate Chrome extension for Facebook group administrators who want to save time and manage member requests more efficiently. Say goodbye to manual data entry and hello to automated member management!

🚀 KEY FEATURES

✅ AUTOMATED DATA COLLECTION
• Automatically scrape pending member request data from your Facebook groups
• Capture names, usernames, join dates, and membership question answers
• Extract email addresses from approval questions
• Track approval status (pending, approved, declined)

✅ GOOGLE SHEETS INTEGRATION
• Seamlessly export member data to your Google Sheets
• One-click synchronization with automatic column mapping

• Keep all your member information organized in one place

✅ WELCOME MESSAGE AUTOMATION
• Send personalized welcome messages to newly approved members
• Use variables like {first_name}, {last_name}, and {group_name}
• Set message intervals and maximum daily limits
• Build stronger community engagement from day one

✅ AUTO-DECLINE FEATURE
• Set rules to automatically decline requests (e.g., missing email)
• Save time on members who don't meet your criteria
• Track decline reasons for future reference
• Focus on quality members who complete all requirements

✅ BEAUTIFUL DASHBOARD
• View all collected member data in a clean, organized interface

## Justification for Permissions

### Storage Permission
**Why we need it:** To store user settings, collected member data, and authentication tokens locally on the user's device.

### Tabs Permission
**Why we need it:** To open the dashboard in a new tab when users click "View Data" button.

### Notifications Permission
**Why we need it:** To notify users when new member requests are detected or when actions are completed.

### Identity Permission
**Why we need it:** To enable Google OAuth for Google Sheets integration, allowing users to sync data.

### Host Permission: facebook.com
**Why we need it:** To access Facebook group pages and scrape member request data that users have permission to view as group administrators.

### Host Permission: docs.google.com
**Why we need it:** To enable users to open their Google Sheets directly from the extension.

### Host Permission: *.supabase.co
**Why we need it:** To communicate with our secure backend for user authentication and data synchronization.
